Configuração e estado de PC-ERP

TCP entrega um fluxo ordenado de bytes e retransmite dados não confirmados. HTTP usa esse fluxo para enviar pedidos e respostas de páginas.

Como ler os campos e testar

Conecte, envie dados e acompanhe SYN, ACK e FIN na timeline. Use Próximo evento ou Reproduzir para avançar.
